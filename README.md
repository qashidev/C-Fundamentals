### About

This repo is a running collection of small C exercises and practice programs, written while learning C fundamentals; structs, pointers, memory management, file I/O, string handling, and general low-level plumbing. 
Each folder is a self-contained exercise rather than one big project (for the time being).

---

### Structure

```
c-fundamentals/
├── 01-structs-fileio/
│   ├── main.c
│   └── README.md
├── 02-.../
└── ...
```

---

### Building

```bash
gcc -Wall -Wextra -o out main.c
./out
```

`-Wall -Wextra` kept on by default; catching warnings early rather than ignoring them.
